# Rankable.io

Rankable.io is a multiplayer Discord Activity where friends build a shared media tier list together in real time. Players join the same lobby, choose a category, and rank cards into S, A, B, C, and F tiers while seeing everyone’s choices and reactions live.

## Game modes

- **Presentation** — Players take turns choosing from the visible cards and presenting their placement to the group.
- **Democracy** — Everyone votes on each card, and the group’s median vote determines its tier.
- **Chaos** — Everyone claims and ranks cards simultaneously in a first-come, first-served race.

Rankable.io includes Discord profiles, randomized turn queues, timed rounds, live card movement, reactions, shared results, and curated categories such as anime and television shows.
